# accessible_input

This is a very simple and mostly self explanatory addon to make the input actions system a bit more accessible in Godot.

The addon sits itself in the left tab bar. So shift tab from your scene tree to the scene tab, then right arrow twice.

Here you have a list of all actions. You can enable or disable showing of built-in actions. If you uncheck this, it will only show the actions that are custom defined for your project. You can add one by entering it's name and deadzone, and pressing add. Then, select it in th elist.

There are buttons to add new events or delete them. Updating events is not supported right now, but it is easy enough to remove the event you messed up and re-add it. Select the kind of event you want in the dropdown, check the modifier boxes if any, and press add event. It will show up in the list.

That's really it. If you want more info, make sure to check the Godot docs for how input actions work.
